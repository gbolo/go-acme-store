# Traefik Integration Example

This guide shows how to integrate `acme-store-fetcher` with Traefik.

## Traefik Configuration

### 1. Main Traefik Config

**File: `/etc/traefik/traefik.yml`**

```yaml
# API and dashboard
api:
  dashboard: true

# Entry points
entryPoints:
  web:
    address: ":80"
  websecure:
    address: ":443"

# Certificate providers
providers:
  # File provider for dynamic configuration
  file:
    directory: /etc/traefik/dynamic
    watch: true  # Auto-reload when files change

# Logging
log:
  level: INFO

accessLog: {}
```

### 2. Directory Structure

```
/etc/traefik/
├── traefik.yml           # Main static config
├── dynamic/              # Dynamic configs (auto-reloaded)
│   ├── acme-certs.yml   # Generated by acme-store-fetcher
│   └── routes.yml       # Your routes/services
└── certs/               # Certificate files
    ├── example.com_cert-chain.pem
    ├── example.com_key.pem
    ├── _wild_.example.com_cert-chain.pem
    └── _wild_.example.com_key.pem
```

### 3. Create Directories

```bash
sudo mkdir -p /etc/traefik/{dynamic,certs}
sudo chmod 755 /etc/traefik /etc/traefik/dynamic
sudo chmod 700 /etc/traefik/certs
```

## Fetch Certificates

### Manual Run

```bash
sudo /usr/local/bin/acme-store-fetcher \
  -config /etc/acme-store/config.yml \
  -output-dir /etc/traefik/certs \
  -traefik-config /etc/traefik/dynamic/acme-certs.yml
```

### Automated with Cron

**File: `/etc/cron.d/acme-traefik`**

```bash
# Fetch ACME certificates every 6 hours
0 */6 * * * root /usr/local/bin/acme-store-fetcher -config /etc/acme-store/config.yml -output-dir /etc/traefik/certs -traefik-config /etc/traefik/dynamic/acme-certs.yml >> /var/log/acme-fetcher.log 2>&1
```

### Automated with Systemd Timer

**Service: `/etc/systemd/system/acme-traefik-fetcher.service`**

```ini
[Unit]
Description=Fetch ACME certificates for Traefik
After=network.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/acme-store-fetcher \
  -config /etc/acme-store/config.yml \
  -output-dir /etc/traefik/certs \
  -traefik-config /etc/traefik/dynamic/acme-certs.yml
User=root
StandardOutput=journal
StandardError=journal
```

**Timer: `/etc/systemd/system/acme-traefik-fetcher.timer`**

```ini
[Unit]
Description=Fetch ACME certificates for Traefik every 6 hours

[Timer]
OnBootSec=5min
OnUnitActiveSec=6h
Persistent=true

[Install]
WantedBy=timers.target
```

**Enable:**

```bash
sudo systemctl daemon-reload
sudo systemctl enable acme-traefik-fetcher.timer
sudo systemctl start acme-traefik-fetcher.timer
sudo systemctl status acme-traefik-fetcher.timer
```

## Generated Configuration

The fetcher creates `/etc/traefik/dynamic/acme-certs.yml`:

```yaml
tls:
  options:
    default:
      minVersion: VersionTLS12
    mintls13:
      minVersion: VersionTLS13
  certificates:
    - certFile: /etc/traefik/certs/example.com_cert-chain.pem
      keyFile: /etc/traefik/certs/example.com_key.pem
    - certFile: /etc/traefik/certs/_wild_.example.com_cert-chain.pem
      keyFile: /etc/traefik/certs/_wild_.example.com_key.pem
```

## Using Certificates in Routes

**File: `/etc/traefik/dynamic/routes.yml`**

```yaml
http:
  routers:
    # Example service with TLS 1.2+
    my-app:
      rule: "Host(`example.com`)"
      entryPoints:
        - websecure
      service: my-app-service
      tls:
        options: default  # TLS 1.2 minimum
    
    # Another service with TLS 1.3 only
    secure-api:
      rule: "Host(`api.example.com`)"
      entryPoints:
        - websecure
      service: api-service
      tls:
        options: mintls13  # TLS 1.3 minimum
    
    # Wildcard domain
    wildcard-app:
      rule: "Host(`app.example.com`) || Host(`test.example.com`)"
      entryPoints:
        - websecure
      service: wildcard-service
      tls:
        options: default

  services:
    my-app-service:
      loadBalancer:
        servers:
          - url: "http://localhost:8080"
    
    api-service:
      loadBalancer:
        servers:
          - url: "http://localhost:8081"
    
    wildcard-service:
      loadBalancer:
        servers:
          - url: "http://localhost:8082"
```

## HTTP to HTTPS Redirect

**File: `/etc/traefik/dynamic/middlewares.yml`**

```yaml
http:
  middlewares:
    redirect-to-https:
      redirectScheme:
        scheme: https
        permanent: true

  routers:
    # Redirect all HTTP to HTTPS
    http-catchall:
      rule: "HostRegexp(`{host:.+}`)"
      entryPoints:
        - web
      middlewares:
        - redirect-to-https
      service: noop

  services:
    noop:
      loadBalancer:
        servers:
          - url: "http://localhost:1"
```

## Benefits

### ✅ **Automatic Reloading**
- Traefik watches `/etc/traefik/dynamic/` directory
- No restart needed when certificates change
- Zero downtime certificate updates

### ✅ **Centralized Management**
- All certificates from one source (Vault)
- Single command updates everything
- Consistent across all services

### ✅ **TLS Options**
- Enforce minimum TLS versions
- Two pre-configured options: `default` (TLS 1.2+) and `mintls13` (TLS 1.3+)
- Apply per-route

## Verification

### Check Traefik Logs

```bash
sudo journalctl -u traefik -f
```

Look for:
```
time="2025-12-12T10:30:00Z" level=info msg="Configuration loaded from file: /etc/traefik/dynamic/acme-certs.yml"
```

### Test HTTPS

```bash
# Test connection
curl -v https://example.com

# Check certificate
openssl s_client -connect example.com:443 -servername example.com < /dev/null

# Check TLS version
curl --tlsv1.3 https://example.com  # Should work with mintls13
curl --tlsv1.2 https://example.com  # Should work with default
```

```
https://your-traefik-host:8080/dashboard/
```

Check:
- Routers → TLS section shows certificates
- TLS → Shows loaded certificates

## Troubleshooting

### Certificates not loading

**Check file permissions:**
```bash
ls -la /etc/traefik/certs/
# Traefik user must be able to read cert files
```

**Check Traefik logs:**
```bash
sudo journalctl -u traefik --no-pager | grep -i error
```

**Verify config syntax:**
```bash
traefik validate --configFile=/etc/traefik/traefik.yml
```

### Auto-reload not working

**Ensure `watch: true` is set:**
```yaml
providers:
  file:
    directory: /etc/traefik/dynamic
    watch: true  # Must be true
```

**Manually trigger reload:**
```bash
# Send SIGUSR1 to Traefik
sudo killall -SIGUSR1 traefik
```

### Wrong certificate served

**Check router rules:**
- Ensure `Host()` rules match certificate domains
- Wildcards need exact match patterns

**Check certificate domains:**
```bash
openssl x509 -in /etc/traefik/certs/example.com_cert-chain.pem -noout -text | grep -A1 "Subject Alternative Name"
```

## Complete Workflow

```
1. acme-store (daemon) obtains certificates
   ↓
2. Stores in Vault
   ↓
3. acme-store-fetcher (cron/timer)
   ├─ Exports to /etc/traefik/certs/*.pem
   └─ Generates /etc/traefik/dynamic/acme-certs.yml
   ↓
4. Traefik detects file change
   ↓
5. Traefik reloads certificates (no restart)
   ↓
6. Services use new certificates automatically
```

## Production Tips

1. **Use separate user**: Run Traefik as dedicated user, not root
2. **Restrict permissions**: `chmod 700 /etc/traefik/certs`
3. **Monitor logs**: Watch for certificate reload events
4. **Test first**: Use staging ACME server for testing
5. **Set up alerting**: Monitor certificate expiration dates
